## Overview

**MirrorSite AI** is an AI-powered platform that transforms any website into production-ready code.

### Key Information

- **URL**: https://mirrorsiteai.vercel.app
- **Technology**: Next.js 15, React, TypeScript, AI Models
- **Pricing**: Token-based (1 token = 1 UGX)
- **Payment**: MTN Mobile Money, Airtel Money
- **Free Tier**: 500 tokens for new users

## How It Works

### Step-by-Step Process

1. **Input Website URL**
   - Enter any publicly accessible URL
   - Or search for websites by keyword

2. **AI Analysis**
   - Firecrawl scrapes content
   - AI analyzes design and structure
   - Extracts components and styles

3. **Code Generation**
   - AI generates React/Next.js code
   - Creates component hierarchy
   - Applies chosen style variations

4. **Preview & Iterate**
   - Real-time preview in browser
   - Chat with AI to make changes
   - Download or deploy code

### Technical Flow

```
User Input → Firecrawl Scraping → AI Analysis → Code Generation → Live Preview
```

## Best Practices

### For Optimal Results

1. **Choose Clear URLs**
   - Use direct page URLs, not homepages
   - Avoid sites with heavy JavaScript/dynamic content
   - Static sites work best

2. **Select Appropriate Styles**
   - Match style to your brand
   - Consider target audience
   - Test different variations

3. **Provide Context**
   - Add additional instructions
   - Specify brand guidelines
   - Mention specific requirements

4. **Iterate with AI**
   - Use natural language for changes
   - Be specific about modifications
   - Test incrementally

### Ethical Considerations

⚠️ **Important Guidelines:**

- Respect copyright and intellectual property
- Use cloned designs as inspiration, not direct copies
- Modify designs significantly for production use
- Credit original designers when appropriate
- Don't clone competitors for malicious purposes
