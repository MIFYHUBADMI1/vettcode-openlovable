## 🚀 Getting Started

### Prerequisites

- Node.js 18+ and npm
- MongoDB database
- API Keys for:
  - Firecrawl (web scraping)
  - E2B (sandboxes)
  - OpenRouter or Groq (AI models)
  - ImageKit (file storage)

### Installation

1. **Clone the repository**

```bash
git clone https://github.com/MIFYHUBADMI1/vettcode-openlovable.git
cd vettcode-openlovable
```

2. **Install dependencies**

```bash
npm install
```

3. **Set up environment variables**

```bash
cp .env.example .env.local
```

Edit `.env.local` with your API keys:

```env
# Required
FIRECRAWL_API_KEY=your_key
E2B_API_KEY=your_key
GROQ_API_KEY=your_key
OPENROUTER_API_KEY=your_key
MONGODB_URI=your_mongodb_uri

# ImageKit
IMAGEKIT_PUBLIC_KEY=your_key
IMAGEKIT_PRIVATE_KEY=your_key
IMAGEKIT_URL_ENDPOINT=your_endpoint

# Auth
NEXTAUTH_SECRET=your_secret
NEXTAUTH_URL=http://localhost:3000
GOOGLE_CLIENT_ID=your_client_id
GOOGLE_CLIENT_SECRET=your_secret
```

4. **Run development server**

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000)

## 📖 Usage

### Clone a Website

1. Go to [Builder](https://mirrorsiteai.vercel.app/builder)
2. Enter a website URL or search for a site
3. Select a design style (optional)
4. Choose your AI model
5. Click "Scrape Site" to start cloning

### Generate Code

1. Navigate to [Generation](https://mirrorsiteai.vercel.app/generation)
2. Your sandbox will be created automatically
3. Use natural language to describe changes
4. AI will generate and apply code
5. Preview changes in real-time

### Search Websites

1. Visit [Search](https://mirrorsiteai.vercel.app/search)
2. Enter keywords or site type
3. Browse results with screenshots
4. Click to clone any site
