# MirrorSite AI - AI Model Information

## About MirrorSite AI
MirrorSite AI is an AI-powered website cloning and code generation platform. We help developers and businesses transform any website into production-ready code in seconds.

## Website URL
https://mirrorsiteai.vercel.app

## Core Features
1. **Website Cloning**: Clone any website's design and structure using AI
2. **AI Code Generation**: Generate production-ready React/Next.js code
3. **Smart Search**: Search and discover websites to clone
4. **Multiple AI Models**: Support for GPT-4, Claude, Gemini, and more
5. **Real-time Preview**: See changes as you build
6. **Token-based Pricing**: Pay-as-you-go model (1 token = 1 UGX)

## Technology Stack
- Frontend: Next.js 15, React, TypeScript, Tailwind CSS
- AI Integration: OpenRouter, Groq, Gemini
- Authentication: NextAuth.js with Google OAuth
- Database: MongoDB
- Deployment: Vercel
- Web Scraping: Firecrawl API

## Pricing Model
- Free tier: 500 tokens for new users
- Pay-as-you-go: 1 UGX = 1 token
- Minimum purchase: 15,000 tokens (15,000 UGX)
- Payment methods: MTN Mobile Money, Airtel Money
